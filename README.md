## 启动

需要 Node.js 22 或更新版本以及该数据库的访问权限。数据库和 AI 密钥仅写在服务端 `.env`，请勿提交或分享这个文件。

```powershell
npm.cmd install
npm.cmd run db:init
npm.cmd run build
npm.cmd start
```

访问 http://127.0.0.1:3210 。如端口占用，可在 `.env` 设置 `PORT`。监听地址固定使用本机；当前版本没有多人账户系统，不应直接开放到公网。部署到公网需增加用户登录、权限、HTTPS 和任务调度服务。

本机重启应用可运行 `launch.ps1`，会在后台启动服务并打开浏览器；日志位于 `logs/`。该脚本不会开启商品采集权限。

初始化读取 `data/sites-seed.json`。重复执行只添加缺少的站点，不覆盖已有备注或关注状态；不改变商品审核状态。只创建 `si_*` 表，不改动已有业务表。

## 功能

- 站点：搜索品牌、网址、介绍和主要产品，筛选国家、类别、股权背景及关注状态，分页、排序、查看依据、保存备注。
- 导出：Excel、CSV、JSON；支持当前筛选及勾选记录。商品导出包含成分依据、剂量、图片地址。单次商品导出上限 10,000 条。
- 商品：原文名称、中文名称、翻译状态、描述、价格/币种、剂型、图片地址、首次发现、最近采集、成分与依据、人工核验状态、历史快照。
- 分析：成分分布、关联商品、剂量及标签依据数量；商品详情保留品牌宣称及警示。
- 关键字：紫白界面新增功效关键字管理，支持中英文、别名、类别、主题/搜索意图、启用/停用、新增、编辑、删除、搜索、导出及关联商品查询。修改匹配词后可创建重新匹配任务，删除词会同步删除关联，停用词立即从有效关联和商品筛选中排除。
- 任务：选择最多 100 个已授权站点，可一键全选；每站 1–1,000 件商品；查看进度、日志及取消任务。也可对所选商品重新分析。
- 分析日志：每个站点实际开始的任务计为一次，商品重新分析任务按站点分别计数。每条记录保存本站序号、累计次数、开始/结束日期、结果、处理商品数、关联任务及失败原因。支持站点/结果/北京时间日期筛选与 Excel、CSV、JSON 导出；站点列表同时显示分析次数和最近分析时间。失败、取消、服务中断计入总次数；仅排队未开始不计入。同一任务同一站点只记一次，重试新任务会增加次数。
- 审核：填写审核清单、审核人和确认文字后开放采集。开放权限不会自动创建任务；仍需创建采集任务。暂停权限会阻止后续写入并取消待执行任务。

## 采集和分析范围

### Google 搜索发现

“搜索发现”按启用的关键字逐个查询 Google 自然搜索结果第 1、2、3 页。默认美国市场、英文关键字，可选择英国、加拿大、德国、法国以及中文关键字。2,000 个词每次最多需要 6,000 次搜索 API 请求，具体额度和费用以 SerpAPI 账户为准；结果变化与地域设置有关，搜索结果不用于推算关键词热度。

Google 本机直连当前超时，采用 [SerpAPI Google Search API](https://serpapi.com/search-api)，分页偏移为 0、10、20。接口密钥可在“搜索发现”页面输入，写入本机服务端 `.search-config.json`（已忽略提交），不返回给前端、不存入 RDS、不写入任务选项或日志；也可用 `SERPAPI_API_KEY` 环境变量配置。本机配置文件优先。请将该文件与 `.env` 一样作为私密配置保管。

未配置密钥时任务状态为“等待搜索接口”，不执行真实搜索；保存密钥后已有等待任务继续执行。密钥失效或额度/速率受限时暂停，任务保留已完成页和判断结果。运行任务可取消。搜索任务和商品任务分别由单独 worker 处理；搜索断点保存在数据库中，服务重启后从未处理页继续，已检索页不会重复计费。

结果保存关键字、实际查询词、市场、页码、排名、页面链接、判断依据和日期。先按公共后缀规则归并品牌域名（含 co.uk），排除电商平台、社交、媒体与医疗机构；再依据公开页面同时存在保健品信息、商品购买证据和站内购买动作判断是否为自营独立站。只判断为独立站的域名自动加入站点库，并进入商品采集队列；新站国家、公开地址和中国背景均保留待核验，不将搜索市场当作公司国家。规则判断不是所有权审计，资料仍需复核。

访问失败、robots 限制、动态渲染或证据不足的页面进入待核验列表，不自动导入。已知独立站按域名关联，重复结果保留搜索来源；24 小时内同一页面的核验结论复用，减少重复访问。新站商品由既有采集器顺序处理，采集任务每批最多 50 个新站，每站上限 1,000 件，自动进行词典翻译、成分提取、图片链接记录和功效关键字关联，写入次数与日期日志。

数据库新增 `si_search_pages`（搜索页与断点）、`si_discovered_pages`（结果和站点判断）、`si_discovery_site_queue`（新站商品任务队列）。Google 真实检索需要可用的 SerpAPI 密钥与额度；当前没有配置密钥，已建立等待任务。

当前初始词表为 20 个类别、200 个编辑整理的功效主题、1,800 个相关搜索意图扩展，共 2,000 条中英文候选词。建词来源为 `editorial_taxonomy_v1`，属于人工分类及规则扩展，没有接入 Google Ads 或第三方搜索量数据；不是经验证的“热度最高 2000 个词”。搜索量、来源、市场及统计日期保留为空，界面显示待核验。按商品匹配数排序只反映数据库中的提及次数，不代表搜索量、销量或广告投放热度。

商品采集、复核及重新匹配会将名称和描述中的中文/英文/别名与启用的关键字表关联，使用英语词边界检查和标点规范化，保留命中词与原文上下文。警告或否定语境单独标记，不纳入有效关联数量。搜索意图词只在明确出现该完整短语时匹配，不因主题命中自动关联所有长尾词。关联是文本提及，不是医学疗效认证；不会根据成分自行推断治疗功效。

后台采集需保持本机及服务运行。全部站点任务顺序处理，新站点优先，Doctor's Best 最后更新；单站失败会记录原因并继续下一站。每站 1,000 件上限、动态页面和访问限制仍可能影响覆盖率，任务开始并不代表已经完成所有站点的全量采集。

支持公开 Shopify 商品目录，辅以商品页面的 Product JSON-LD，以及公开 sitemap/商品链接。采集遵守 robots.txt，默认同站请求间隔至少 1 秒，也遵守更长的 Crawl-delay。每站请求上限按采集数量计算，最多 1,500 个请求、10 个站点地图、20 页 Shopify 目录。响应限制 3 MB、18 秒超时，不绕过登录、验证码或访问限制。重定向和 DNS 均检查域名及公共网络地址。达到采集数量上限时，日志标明并非全量。

图片当前记录官网图片 URL，并在详情显示；没有上传本地副本。图片中的营养标签暂不做 OCR。仅有图片标签或复杂动态页面的站点需后续适配；无法识别成分或剂量会保留为空并标记待核验。站点正常采集到 0 件时，日志会记录需适配的原因。商品列表可能含站内其他健康相关产品，除常见服装、礼品卡等周边外，最终分类仍需人工核验。

默认使用常见成分词典，区分营养标签文本和营销描述提及；优先逐行读取营养标签表格，不把硬脂酸镁等辅料当作有效矿物质，也不将维生素原料中的矿物名称误作独立成分。只有明确剂量才记录。中文名称只是词典辅助翻译，缺少完整翻译时标记待翻译/部分翻译。结果不代表医学疗效、法规合规或销量评估。

可在 `.env` 配置兼容 Chat Completions 的 AI 服务：

```dotenv
AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=填入自己的密钥
AI_MODEL=填写服务商支持的模型名称
```

重启服务后生效。AI 进行中文翻译及有证据的成分/品牌宣称提取，剂量和引文必须逐字出现在商品原文中；失败时回退到词典分析，并标记待核验。分析前需人工确认来源，所有分析结果仍需人工核验。目前未配置 AI 密钥，完整自动翻译尚未启用。

“首次发现”是系统首次采集时间，不代表上市时间；原站发布时间会在 Shopify 原始数据中保留。当前功能没有 Meta 广告投放核验、销量或广告花费数据。该应用用于站点和商品资料库，后续可接广告数据源及周期监测。

## 数据库

`si_sites` 站点；`si_products` 商品；`si_product_images` 图片；`si_product_ingredients` 成分；`si_product_snapshots` 快照；`si_keywords` 关键字；`si_product_keywords` 商品关联与文本证据；`si_jobs` 任务；`si_job_events` 日志；`si_site_analysis_runs` 站点分析次数与日期；`si_settings` 审核设置；`si_audit_log` 审计记录。

所有商品写入及分析更新在事务中锁定审核设置，保证暂停权限后不能继续写入。运行中的任务在服务重启后停止，不自动重跑；队列中的任务只在审核通过后执行。单进程 worker 顺序处理任务，适用于当前 100 站点的人工启动采集，暂不支持多服务实例。

中国背景结论严格区分控股、参股、历史投资和运营团队。6 条中资线索中包含历史披露；不能据此确认中国卖家运营。公开地址含联系、法务、仓库等不同类型，不能统一称为总部。

当前 RDS 连接不提供 SSL，使用服务端环境设置 `DB_SSL=false`；RDS 开启 TLS 后可改为 `DB_SSL=true`，必要时设置 `DB_SSL_CA_FILE`。未在日志、响应或导出中暴露数据库登录凭据。

## 验证

按最新规则复核某站点已入库商品，可运行 `node server/reanalyze-site.mjs 1`（将 `1` 替换为站点编号）。该工具不再抓取网页，不改变授权，要求当前站点已授权且没有运行中的任务；会注册独立分析任务和站点次数/日期日志，使用与队列相同的处理函数。

```powershell
npm.cmd test
node tests/smoke.mjs
```

核心 37 项测试使用本地虚构页面，不访问或录入真实商品。`tests/smoke.mjs` 和 `tests/site-runs-smoke.mjs` 分别用于初始未开放与仅首站授权的历史验收。当前全部站点开放后使用 `node tests/keywords-smoke.mjs`，检查 2,000 条词表、关联证据、商品筛选、导出、后台范围任务和桌面/手机界面；会创建并清理一条临时关键字，不创建采集任务或更改授权。另可运行 `node tests/discovery-smoke.mjs` 核验新名称、等待接口的 6,000 页任务、密钥不泄漏及桌面/手机页面，不发起真实搜索。需要启动应用、系统 Microsoft Edge 及可用的 Playwright 安装。
